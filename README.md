# Официальная документация языка программирования Haiku 📝

Haiku — это ультраминималистичный, легкий и интерактивный язык программирования, построенный поверх экосистемы Python. Он спроектирован для быстрого написания скриптов автоматизации, консольных утилит безопасности, текстовых квестов и графических ретро-игр.

Исходные файлы кода используют расширение **`.haiku`**.

---

## 🚀 1. Системные требования и управление (CLI)

Управление запуском и компиляцией программ осуществляется через единую консольную утилиту `haiku` из любого терминала Linux:

* **Интерпретация (запуск кода напрямую):**
  ```bash
  haiku run имя_файла.haiku
  ```
* **Компиляция проекта:**
  ```bash
  haiku build имя_файла.haiku
  ```
  При компиляции исходный код транслируется и автоматически сохраняется в изолированную папку сборки `haiku-builds/` в виде готового `.py` скрипта. На экран выводится системное уведомление: `Код скомпилирован!`

---

## 📦 2. Работа с переменными

Создание переменных происходит с помощью ключевого слова `ware`. Язык использует динамическую типизацию. Для того чтобы вызвать значение переменной из памяти или встроить её прямо внутри выводимой текстовой строки, перед её именем обязательно ставится символ `$`.

```text
ware test = "Ohhhh Helllooooo guuuy"
print("Сообщение из памяти: $test")
```

---

## 🎨 3. Визуальные эффекты и работа с консолью

В ядро Haiku встроены инструменты стилизации консольного вывода:

* **`animPrint("текст")`** — анимированный посимвольный вывод строки на экран (эффект симуляции печатающейся машинки).
* **`rainbow("текст")`** — выводит строку, где каждая буква динамически и случайно окрашена во все цвета радуги.
* **`color("название_цвета")`** — переключает цвет всего последующего вывода текста в терминале.
  * *Доступная палитра цветов:* `red`, `green`, `yellow`, `blue`, `purple`, `cyan`, `white`, `reset` (сброс цвета на стандартный).
* **`line()`** — автоматически высчитывает геометрические размеры окна текущего терминала и рисует ровную горизонтальную разделительную линию во всю ширину экрана.
* **`cls()`** — мгновенно очищает активный буфер экрана консоли.
* **`sleep(число)`** — временно приостанавливает выполнение программы на заданное время. Поддерживает дробные значения (например, `sleep(1.5)`).

---

## 🛠 4. Криптография и системные утилиты

* **`genpas()`** — мгновенно генерирует случайный криптостойкий мастер-пароль повышенной сложности из 16 символов (включая цифры, спецсимволы и буквы разного регистра).
* **`input("приглашение")`** — останавливает поток выполнения и ожидает от пользователя ввода текстовых данных в консоль.
* **`sys("команда_ось")`** — позволяет выполнять любые нативные системные команды хост-системы (например, `sys("uname -a")` или `sys("ls -la")`).

## 🔄 5. Управление потоком (Условия и Циклы)

### Конструкции ветвления (`if`, `elif`, `else`)
Haiku поддерживает блоки условий для проверки равенства (`==`) или неравенства (`!=`). Вложенный код отделяется четырьмя пробелами или табуляцией, а сама строка проверки заканчивается двоеточием `:`:

```text
ware key = random(1, 2)
if $key == "1":
    print("Условие True! Выпала единица.")
else:
    print("Сработал fallback-блок. Выпала двойка.")
```

### Бесконечные фреймы и завершение
* **`loop`** — маркер глобального бесконечного цикла. Если это ключевое слово объявлено в коде файла, программа автоматически зацикливается и выполняется по кругу, пока её не прервут вручную (через Ctrl+C).
* **`stop`** — вызывает мгновенное завершение работы программы и осуществляет безопасный выход из запущенного процесса.

## 🐢 6. Графический движок Turtle

В Haiku интегрировано графическое окно управления векторным объектом (Черепашкой). При перемещении по координатной сетке Черепашка оставляет за собой след на черном фоне, позволяя создавать полноценные рисовалки.

* **`turtle("readyWindow")`** — инициализирует графический конвейер, выставляет геометрию окна `600x600`, красит фон в черный цвет и создает Черепашку.
* **`turtle("controlWASD")`** — включает прослушивание клавиатуры на классические клавиши движения. При нажатии на **W** (вверх), **A** (влево), **S** (вниз), **D** (вправо) объект перемещается на 20 пикселей в соответствующую сторону, оставляя белый след.
* **`turtleSkin("название_скина")`** — меняет аватар самого графического объекта. Доступны скины: `classic`, `turtle`, `square`, `circle`, `triangle`, `arrow`.
* **`turtleColor("название_цвета")`** — меняет цвет линии рисования и самого объекта в окне (поддерживает стандартные веб-цвета, например `red`, `cyan`, `green`).
* **`turtle("circle")`** — команда заставляет объект автоматически нарисовать круг радиусом 50 пикселей.
* **`turtle("clear")`** — полностью очищает графическое окно от всех нарисованных линий.

## 👩‍💻 7. Пример комплексной программы на Haiku

Пример полноценного интерактивного скрипта с использованием основных возможностей синтаксиса Haiku:

```text
cls()
color("cyan")
animPrint("--- ИНТЕРАКТИВНАЯ HAIKU-СИСТЕМА ---")
line()

color("green")
ware user = "Кодер"
print("[Авторизация]: Добро пожаловать, \$user.")

color("white")
input("Нажмите Enter, чтобы начать сессию и сгенерировать токен безопасности...")

line()
genpas()
line()

ware play_game = "yes"
if \$play_game == "yes":
    color("yellow")
    animPrint("Запуск графической среды рисования Черепашки...")
    sleep(1.5)
    
    turtle("readyWindow")
    turtleSkin("triangle")
    turtleColor("cyan")
    turtle("controlWASD")

loop
```
